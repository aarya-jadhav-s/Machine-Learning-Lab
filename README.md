# Machine Learning Lab 🧪

**A 360° exploration of Machine Learning with Aarya!** ❤️

Welcome to my **Machine Learning Lab** — a hands-on journey into understanding and implementing Machine Learning algorithms.

This repository documents my learning process through practical experiments, exploring the mathematics behind algorithms, understanding how models work, experimenting with different techniques, and evaluating their performance.

My goal is to build a strong foundation in Machine Learning by implementing algorithms step by step and learning through practical application.

## 🎯 What This Repository Covers

This lab explores different Machine Learning concepts and algorithms, including:

### Supervised Learning

- Linear Regression
- Lasso Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Decision Trees
- Random Forest
- Support Vector Machines (SVM)

### Unsupervised Learning

- K-Means Clustering
- Hierarchical Clustering
- DBSCAN
- Principal Component Analysis (PCA)

*More algorithms and experiments will be added as I progress.*

## 🛠️ Tech Stack

- **Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Environment:** Jupyter Notebook
